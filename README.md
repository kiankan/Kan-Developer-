# kan_checker — ربات تلگرام مدیریت هاست اشتراکی cPanel

با این ربات می‌تونید هاست اشتراکی cPanel خودتون (دامنه/آی‌پی + یوزرنیم +
رمز یا API Token) رو به تلگرام معرفی کنید و از همون‌جا مدیریتش کنید: دیدن
فضای دیسک، دامنه‌ها، ساخت/حذف ایمیل، دیتابیس MySQL، اکانت FTP، ویرایش
رکوردهای DNS و تغییر رمز اکانت.

هر چت تلگرام فقط به هاستی که خودش وصل کرده دسترسی داره؛ اطلاعات ورود قبل
از ذخیره روی دیسک رمزنگاری می‌شه (بخش «امنیت» رو ببینید).

## قابلیت‌ها

- `/connect` — ویزارد قدم‌به‌قدم برای وصل‌کردن هاست (آدرس، پورت، یوزرنیم،
  رمز عبور یا API Token). قبل از ذخیره، اتصال تست می‌شه.
- `/disconnect` — قطع اتصال و پاک‌کردن کامل اطلاعات هاست از ربات.
- `/info` — اطلاعات اکانت و فضای دیسک استفاده‌شده.
- `/domains` — لیست دامنه اصلی، زیردامنه‌ها، addon و parked domains.
- `/subdomain add <نام> <دامنه> [مسیر]` و `/subdomain del <زیردامنه‌کامل>`
- `/email list [دامنه]`، `/email add <ایمیل> <رمز> [حجم‌مگابایت]`،
  `/email passwd <ایمیل> <رمزجدید>`، `/email del <ایمیل>`
- `/db list`، `/db create <نام>`، `/db delete <نام>`،
  `/db user add <یوزر> <رمز>`، `/db user del <یوزر>`،
  `/db grant <یوزر> <دیتابیس> [دسترسی=ALL PRIVILEGES]`
- `/ftp list`، `/ftp add <یوزر> <رمز> [حجم‌مگابایت=0 یعنی نامحدود]`،
  `/ftp del <یوزر>`
- `/dns list <دامنه>`، `/dns add <دامنه> <نام> <نوع> <مقدار> [ttl]`،
  `/dns del <دامنه> <شماره‌خط>`
- `/password` — ویزارد تغییر رمز اکانت cPanel (رمز فعلی + رمز جدید).
- `/files list [مسیر]`، `/files view <مسیر>`، `/files write <مسیر>`
  (محتوای جدید رو در پیام بعدی می‌فرستید — کل فایل جایگزین می‌شه)،
  `/files mkdir <مسیر-والد> <نام>`، `/files rename <قبلی> <جدید>`،
  `/files copy <مبدأ> <مقصد>`، `/files del <مسیر>` — فایل‌منیجر.
- `/ssh <دستور>` — اجرای واقعی دستور شل روی سرور، از طریق SSH. فقط با
  اتصال «رمز عبور» کار می‌کنه (نه API Token) و فقط اگه SSH روی هاست‌تون
  فعال باشه. `/sshport <پورت>` اگه SSH‌تون روی پورت غیراستاندارد (نه ۲۲) باشه.
- `/raw <ماژول> <تابع> [کلید=مقدار ...]` — فراخوانی مستقیم و پیشرفته‌ی
  UAPI cPanel، برای مواردی که دستور اختصاصی براشون نساختیم. برای رابط
  قدیمی‌تر (`json-api/cpanel`) از پیشوند `api2:` روی نام ماژول استفاده کنید،
  مثلاً: `/raw api2:ZoneEdit fetchzone domain=example.com`
- `/status` برای همه در دسترسه؛ `/admin` (فقط ادمین) برای روشن/خاموش‌کردن
  دسترسی عمومی و ویرایش پیام خوش‌آمد.
- هر پیام حاوی رمز/توکن (چه در ویزارد، چه در دستورهایی مثل `/email add`)
  بلافاصله بعد از پردازش از چت پاک می‌شه.

> بعضی از این دستورها (`/subdomain`، `/dns`، `/password`) روی رابط
> قدیمی‌تر ولی هنوز کاملاً پشتیبانی‌شده‌ی cPanel (`API 2`) اجرا می‌شن،
> چون معادل رسمی‌شون در UAPI جدید وجود نداره. شکل دقیق بعضی فیلدهای پاسخ
> ممکنه بین نسخه‌های مختلف cPanel کمی فرق کنه؛ اگه رندر یک پاسخ رو نشناخت
> خودش خروجی خام JSON رو نشون می‌ده، و همیشه با `/raw` می‌تونید هر تابعی
> رو مستقیم و بدون واسطه صدا بزنید.

> ⚠️ **درباره‌ی `/ssh`:** cPanel هیچ endpoint سبکی برای «اجرای یک دستور و
> گرفتن خروجی» نداره (ترمینال واقعی‌ش یک اتصال WebSocket تعاملیه، مخصوص
> مرورگر). به همین خاطر `/ssh` مستقیماً با پروتکل SSH (نه از طریق cPanel)
> به سرورتون وصل می‌شه و دستور رو اجرا می‌کنه — یعنی این دستور واقعاً
> دسترسی کامل شل به سرورتون می‌ده، دقیقاً هم‌سطح با داشتن رمز SSH خودتون.
> این هم یعنی هر کسی که به این چت تلگرام دسترسی داشته باشه، به سرورتون هم
> دسترسی داره؛ `ADMIN_ID` و خاموش‌نگه‌داشتن «حالت عمومی» رو جدی بگیرید.



## راه‌اندازی سریع (روی سرور، systemd)

```bash
bash <(curl -Ls https://raw.githubusercontent.com/kiankan/kan_checker/main/kancheckerctl) install
```

توکن ربات (از @BotFather) و آیدی عددی ادمین (از @userinfobot) رو می‌پرسه؛
بعدش سرویس رو با systemd بالا میاره. برای مدیریت بعدی:

```bash
kancheckerctl            # منو
kancheckerctl update     # آپدیت
kancheckerctl status     # وضعیت
kancheckerctl logs       # لاگ زنده
```

## راه‌اندازی با Docker

```bash
bash <(curl -Ls https://raw.githubusercontent.com/kiankan/kan_checker/main/install.sh)
```

یا دستی:

```bash
cp .env.example .env   # و پرکردن TELEGRAM_BOT_TOKEN / ADMIN_ID
docker compose up -d --build
```

## راه‌اندازی دستی (بدون نصب‌کننده)

نیاز: PHP 8.1+ با پسوندهای `curl`، `openssl`، `mbstring`، و [Composer](https://getcomposer.org/).

```bash
cp .env.example .env    # و پرکردن مقادیر
composer install --no-dev   # برای دستور /ssh (phpseclib) — بدونش هم بقیه‌ی ربات کار می‌کنه
php bot.php              # حالت long-polling
```

یا برای حالت webhook، `webhook.php` رو پشت یک وب‌سرور HTTPS بذارید و آدرسش
رو با `php cli.php webhook:set <url>` به تلگرام معرفی کنید.

## امنیت

- رمز/توکن هر هاست فقط برای همون چت تلگرامی که وصلش کرده ذخیره می‌شه، با
  AES-256-GCM رمزنگاری‌شده روی دیسک (`data/hosts.json`)، نه به‌صورت متن ساده.
- کلید رمزنگاری از `APP_KEY` (در `.env`) خونده می‌شه؛ اگه ندید، ربات خودش
  یک کلید تصادفی می‌سازه و در `data/app.key` نگه می‌داره. برای بکاپ/مهاجرت
  امن‌تر، خودتون یکی بسازید (دستور داخل `.env.example` هست) و در `.env`
  ثابت نگهش دارید — وگرنه بعد از جابه‌جایی/پاک‌شدن `data/`، اتصال‌های
  ذخیره‌شده دیگه رمزگشایی نمی‌شن و باید دوباره `/connect` بزنید.
- هر پیامی که رمز/توکن توش هست (چه از ویزارد، چه آرگومان یک دستور) بلافاصله
  بعد از خوندن از چت تلگرام پاک می‌شه.
- پوشه‌ی `data/` (شامل `hosts.json`، `app.key`، وضعیت‌های موقت) در
  `.gitignore` هست و هرگز نباید commit یا جایی به اشتراک گذاشته بشه.
- اتصال به هاست همیشه روی HTTPS انجام می‌شه؛ اگه هاست شما گواهی معتبر نداره
  می‌تونید موقتاً `CPANEL_INSECURE_SSL=1` بذارید، ولی برای هاست واقعی توصیه
  نمی‌شه.
- دسترسی به کل ربات با `ADMIN_ID` و «حالت عمومی» (از پنل `/admin`) کنترل
  می‌شه — اگه فقط خودتون قراره ازش استفاده کنید، `ADMIN_ID` رو ست کنید و
  حالت عمومی رو خاموش نگه دارید.
- `/ssh` و `/files write`/`/files del` قدرت واقعی زیادی می‌دن (اجرای دستور
  شل، بازنویسی/حذف فایل روی سرور). این‌ها را دقیقاً هم‌سطح با در دست داشتن
  رمز هاست‌تون در نظر بگیرید و مراقب باشید چه کسی به این چت تلگرام دسترسی داره.

## توسعه

- `bot.php` — حالت long-polling (پیش‌فرض).
- `webhook.php` — نقطه‌ورودی حالت webhook.
- `cli.php` — دستورهای خط‌فرمان (`webhook:set`، `webhook:delete`، و `test`
  برای تست مستقیم اتصال به یک هاست بدون تلگرام).
- `src/CpanelClient.php` — لایه‌ی ارتباط با cPanel (UAPI + API 2 قدیمی).
- `src/UpdateHandler.php` — منطق دستورهای تلگرام.
- `src/HostStore.php` / `src/Crypto.php` — ذخیره‌ی رمزنگاری‌شده‌ی اتصال هر چت.
- `src/ConversationState.php` — وضعیت ویزاردهای چندمرحله‌ای (`/connect`,
  `/password`, `/files write`).
- `src/SshClient.php` — اجرای دستور شل روی سرور از طریق SSH (با phpseclib؛
  اختیاریه، بدون `composer install` فقط همین یک دستور غیرفعال می‌مونه).
- `src/Render.php` — قالب‌بندی پاسخ‌های cPanel برای تلگرام.
