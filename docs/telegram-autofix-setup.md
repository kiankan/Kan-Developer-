# راه‌اندازی هشدار Kan GitHub AutoFix در تلگرام

این راهنما نحوهٔ دریافت هشدار از گردش‌کار GitHub Actions را توضیح می‌دهد. برای اعلان یک‌طرفه، نیازی به اجرای دائمی ربات روی VPS نیست؛ GitHub Actions مستقیماً API رسمی تلگرام را صدا می‌زند. VPS فقط در صورت نیاز به قابلیت‌های بیشتر در آینده اختیاری است.

## ۱. ساخت ربات اختصاصی

1. در تلگرام گفت‌وگوی حساب رسمی @BotFather را باز کنید.
2. دستور /newbot را بفرستید و نام نمایشی و نام کاربری یکتا که به bot ختم می‌شود انتخاب کنید.
3. توکن دریافتی را محرمانه نگه دارید؛ آن را در مخزن، Issue یا چت عمومی منتشر نکنید.

## ۲. انتخاب مقصد پیام

- **گفت‌وگوی خصوصی:** ربات را باز کنید و /start بفرستید.
- **گروه:** ربات را به گروه اضافه کنید و مطمئن شوید اجازهٔ ارسال پیام دارد.
- **کانال:** ربات را مدیر کانال کنید و مجوز ارسال پست بدهید.

شناسهٔ مقصد (chat_id) را از روشی مطمئن به‌دست آورید. توکن ربات یا پاسخ کامل API که ممکن است اطلاعات حساس داشته باشد را منتشر نکنید.

## ۳. افزودن اسرار GitHub

به [Settings → Secrets and variables → Actions](https://github.com/kiankan/Kan-Developer-/settings/secrets/actions) بروید و این Repository secrets را اضافه کنید:

- OPENAI_API_KEY — کلید OpenAI برای تحلیل خطاها.
- TELEGRAM_BOT_TOKEN — توکن دریافت‌شده از BotFather.
- TELEGRAM_CHAT_ID — شناسهٔ مقصد پیام.

هیچ‌کدام از این مقادیر را در فایل YAML، کد منبع، Issue یا کامیت قرار ندهید.

## ۴. وضعیت گردش‌کار

گردش‌کار اکنون در شاخهٔ اصلی قرار دارد: [مشاهدهٔ فایل Workflow](../.github/workflows/kan-autofix.yml).

پس از افزودن اسرار، به **Actions → Kan GitHub AutoFix** بروید. گردش‌کار برای اجرای ناموفق GitHub Actions به‌طور خودکار اجرا می‌شود؛ اجرای دستی نیز با شناسهٔ اجرای ناموفق (run_id) امکان‌پذیر است.

## ۵. آزمایش ایمن

1. به ربات خصوصی پیام /start بدهید یا مطمئن شوید در گروه/کانال دسترسی ارسال دارد.
2. وجود هر سه Secret را بررسی کنید و فاصلهٔ اضافی ابتدا یا انتهای مقدارها را حذف کنید.
3. در Actions گردش‌کار **Kan GitHub AutoFix** را باز کنید و **Run workflow** را بزنید.
4. در ورودی run_id شناسهٔ یک اجرای ناموفق را وارد کنید.
5. لاگ را بررسی کنید. پیام **Telegram failure alert sent.** یعنی API تلگرام درخواست ارسال را پذیرفته است. اگر پیام **Telegram alert skipped** را دیدید، یکی از دو Secret تلگرام تنظیم نشده است.

اگر برای همان run_id قبلاً Issue گزارش ایجاد شده باشد، گردش‌کار برای جلوگیری از گزارش تکراری خارج می‌شود و ممکن است اعلان دیگری نفرستد. برای آزمون سرتاسری، از یک اجرای ناموفق جدید و بی‌خطر استفاده کنید؛ کد اصلی را عمداً خراب نکنید.

## محدودهٔ امنیتی

این گردش‌کار علت احتمالی خطا را گزارش می‌کند و در صورت تنظیم Secretها هشدار تلگرام می‌فرستد. **کد را تغییر نمی‌دهد، پچ هوش مصنوعی را اعمال نمی‌کند و چیزی را خودکار ادغام نمی‌کند.** پیشنهادها را قبل از استفاده بررسی و آزمایش کنید.
